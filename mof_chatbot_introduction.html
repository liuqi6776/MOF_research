1. Zero-Shot Prediction
未知 CIF 零样本即时预测

Upload any unseen CIF outside the 252 library. The system extracts its 3D geometry & 768-dim embeddings in milliseconds to instantly predict $CO_2$ uptake (0.15/1.0 bar), selectivity, $Q_{st}$, and parasitic energy.
上传任何不在 252 数据库中的全新 CIF 文件，系统毫秒级解析其晶胞参数并调用融合 QSAR 模型，即时预测烟气吸附量、选择性、吸附热与能耗。
🛠️

2. Inverse Design
目标导向逆向结构优化

Specify target goals (e.g. Selectivity >30, lower regeneration energy). The AI computes QSAR partial dependence sensitivity to generate actionable 4-step modification strategies (pore sieving, OMS, linkers).
指定期望性能（如选择性 >30、降低能耗），AI 基于 QSAR 偏依赖敏感度自动生成针对性的孔径筛分收缩、开放金属位点引入与配体修饰 4 步改性清单。
🌐

3. Multi-Modal Graph RAG
多模态图检索增强

Dual-channel retrieval combining 768-dim structural cosine similarity with a 1042-edge Knowledge Graph. Discovers Pareto-optimal analogues and green metal replacements without hallucination.
结合 768 维结构余弦相似度与 1042 边异构知识图谱进行双通道检索，精准匹配近邻优选材料与环保金属替代方案，杜绝大模型学术幻觉。
⚛️

4. 3D Crystal Studio
交互式 3D 晶体空间视图

Integrated 3Dmol.js WebGL crystal engine supporting 360° rotation, pan, zoom, unit cell boundaries, and dynamic pore descriptor cards on both desktop and mobile browsers.
内置 3Dmol.js WebGL 晶体渲染引擎，支持周期性晶胞、球棍模型 360° 旋转平移缩放，并在 PC 与移动端实时呈现晶胞与微孔参数。
System Architecture / 系统全景架构

🏗️ End-to-End Pipeline & Technical Flow / 端到端技术架构

MatterChat Multi-Modal Paradigm & Fused Representation Learning / 多模态融合表征与物理图谱增强流程

1
3D Crystal Input
3D 晶体特征提取
Input / 输入: User-uploaded CIF or 252 Database Preset (用户上传 CIF 或 252 数据库预置材料)
Feature Extraction / 特征提取: Lattice cell parameters $(a,b,c,\alpha,\beta,\gamma)$, theoretical density, atomic radial distribution function (RDF), and coordination topology $\to$ 768-dim Normalized Structural Vector $X_{\text{emb}}$.
2
Fused Representation
多模态融合表征矩阵
Fusion Architecture / 融合结构: Concatenates 9-dim physical pore descriptors ($\text{PLD, LCD, ASA, Void Fraction}$) with 16-dim PCA principal components of $X_{\text{emb}}$:
$$\mathbf{X}_{\text{fused}} = \left[ \mathbf{X}_{\text{trad}} (9\text{d}), \ \text{PCA}_{16}(\mathbf{X}_{\text{emb}}) (16\text{d}) \right] \in \mathbb{R}^{25}$$ Scientific Advantage: Enforces hard physical geometric constraints while encoding latent local coordination microenvironments.
3
Multi-Target QSAR ML
多目标 QSAR 模型预测
Trained Ensemble Regressors (`results/models/mof_property_predictors.joblib`):
Predicts 6 core performance metrics simultaneously: $q_{\text{CO2}@0.15\text{bar}}$, $q_{\text{CO2}@1.0\text{bar}}$, $\text{Selectivity}_{\text{CO2/N2}}$, $Q_{st}$, $\text{Capacity}_{\text{VSA}}$, $\text{PE}_{\text{VSA}}$.
4
Graph RAG & Reasoning
图谱增强与逆向设计推理
Knowledge Graph & LLM Engine (`scripts/mof_graph_rag_engine.py`):
Injects structural embeddings, predicted properties, sensitivity-based modification rules, and Graph RAG candidate materials into DeepSeek LLM to generate structured scientific reasoning reports and actionable chemical modification paths.
